LiftNotes помогает вспомнить, как прошла силовая тренировка, и сравнить результаты за разные дни. Перед новым занятием в дневнике можно посмотреть, с каким весом выполнялось упражнение и сколько было повторений. В конце недели можно посмотреть, сколько занятий было и сколько времени на них ушло. Так же можно проконсультироваться с ии-ассистентом по вопросам спорта.

Пользовательские сценарии

Просмотр истории тренировок. Пользователь находит занятие в дневнике по дате и открывает его карточку. Для каждого упражнения доступны рабочий вес и количество повторений по подходам.

Оценка прогресса. В разделе «Прогресс и нагрузка» пользователь сравнивает рабочий вес по датам, а также количество и общую длительность занятий по неделям. Из таблицы прогресса можно перейти к карточке тренировки и проверить данные по подходам.

Проверка рекомендации. Пользователь знакомится с демонстрационным советом и по ссылкам переходит к тренировкам, на которых он основан.

Экраны приложения

Дневник открывается по адресу `/`. Это главная страница со списком тренировок по неделям. Для каждого занятия видны дата, длительность и упражнения. Нажатие на название открывает карточку тренировки.

Карточка тренировки открывается по адресу `/workouts/:id`. В ней есть дата, длительность, список упражнений, вес и повторы каждого подхода, а также заметка, если она есть. По ссылке «К дневнику» можно вернуться к списку.

Раздел «Прогресс и нагрузка» открывается по адресу `/progress`. Первая таблица показывает самый большой рабочий вес в записанных подходах жима за каждую дату. Вторая показывает число занятий и суммарное время по неделям.

Раздел «Рекомендации» открывается по адресу `/recommendations`. В итоговой версии ИИ-модуль будет анализировать историю тренировок, включая рабочий вес и количество повторений, и формировать персональные рекомендации.

Запуск

Проект сделан на React и TypeScript. Переходы между страницами работают через React Router, меню использует Material UI. Для запуска и сборки используется Vite.

Для запуска нужны Node.js и npm. Проект запускался на Node.js 26.13.0 и npm 11.20.0. Из папки проекта перейди в `frontend`, выполни `npm ci`, затем `npm run dev -- --host 127.0.0.1`. Открой в браузере адрес из строки `Local` в терминале. Сборку можно проверить командой `npm run build`, код проверить через `npm run lint`.

Скриншоты экранов лежат в папке `docs/screenshots`.
